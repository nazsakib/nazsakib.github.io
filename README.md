# Sakib MD Nazmush — Technical Portfolio

### 🚀 Modern Engineering Showcase

This is the source code for my professional portfolio website, built with **React**, **TypeScript**, **Tailwind CSS**, and **Framer Motion**. It showcases my expertise as a Technical Support Engineer, Automation Specialist, and WordPress Developer.

---

## 🛠️ Tech Stack

*   **Frontend:** React 18, TypeScript, Vite
*   **Styling:** Tailwind CSS, shadcn/ui, Framer Motion (Animations)
*   **Icons:** Lucide React
*   **Analytics:** Vercel Web Analytics
*   **Form Handling:** Formspree Integration

---

## 🏗️ Project Architecture

The site is built using a component-based architecture for scalability and clean code standards:

```text
/src
├── /components      # Reusable UI components
│   └── /portfolio   # Section-specific components (Hero, About, etc.)
├── /hooks           # Custom React hooks
├── /lib             # Utility functions
├── /pages           # Main page layouts
└── /types           # TypeScript interfaces
```

## 🛠️ Local Development

To run this project locally on your machine:

1.  **Clone the repository:**
    ```sh
    git clone https://github.com/nazsakib/nazsakib.github.io.git
    ```

2.  **Install dependencies:**
    ```sh
    npm install
    ```

3.  **Start the development server:**
    ```sh
    npm run dev
    ```

4.  **Open your browser:**
    Navigate to `http://localhost:5173` (or the port shown in your terminal).
